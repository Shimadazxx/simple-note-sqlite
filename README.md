# Simple Note App (Flutter + SQLite)

**Simple Note App** adalah aplikasi manajemen catatan sederhana yang dibangun menggunakan **Flutter** dan **SQLite** (`sqflite`). Aplikasi ini dirancang untuk mencatat tugas, ide, atau pengingat harian dengan penyimpanan data lokal di perangkat pengguna (*offline-first*).

---

## 🚀 Fitur Utama
- **CRUD Operations**: Tambah, baca, ubah, dan hapus catatan secara real-time.
- **Penyimpanan Lokal**: Menggunakan SQLite melalui package `sqflite` sehingga data tersimpan aman di dalam penyimpanan internal HP tanpa memerlukan koneksi internet.
- **Antarmuka Responsif**: Tampilan antarmuka yang bersih, intuitif, dan mudah digunakan.

---

## 🛠️ Teknologi & Library
- **Framework**: [Flutter](https://flutter.dev/)
- **Bahasa Pemrograman**: [Dart](https://dart.dev/)
- **Database**: `sqflite` (Penyimpanan database SQL lokal)
- **State Management**: Stateful Widgets / Native Flutter State
